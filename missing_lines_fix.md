# Missing Lines Fix (2026-02-06)

## Problem

The Iliad had 15,682 lines instead of the expected 15,693 (11 missing), and the Odyssey had 12,109 instead of 12,110 (1 missing). All missing lines were at the ends of books, caused by truncations in the upstream Chamberlain HTML source files used by the legacy pipeline to generate enhanced mora grid files.

## Root Cause

The enhanced mora grid files in `output/run_1/` were generated by the legacy pipeline (`lyresong_complete.py`) from David Chamberlain's HTML scansion files (`homer_texts/*/html/`). Those HTML files were truncated at the ends of the 6 affected books. The same truncations exist in Chamberlain's CSV data hosted at hypotactic.com.

## Fix

Used `text_scanner.py`'s scanning functions to generate the missing lines from Perseus project source data:

- **Iliad lines**: Scanned from Perseus AGDT treebank v1.6 per-book XML files (`data-sources/treebank_data/v1.6/greek/data/tlg0012.tlg001.perseus-grc1_*.tb.xml`) using `generate_enhanced_file()` in treebank-driven mode.
- **Odyssey 2.434**: The treebank also lacked this line, so it was scanned from the Perseus TEI text XML (`data-sources/canonical-greekLit/data/tlg0012/tlg002/tlg0012.tlg002.perseus-grc2.xml`) using `tokenize_tei_line()` and `process_line()`.

The scanned lines were appended to the existing enhanced files and verified for:
- Correct 24-mora hexameter format
- No duplicate line numbers
- Successful melody generation with the West pipeline
